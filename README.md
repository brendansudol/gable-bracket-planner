# Gable Bracket Planner

An interactive mockup for trying out decorative gable bracket placements on our house.

Drag a bracket along the roofline to move it. Brackets can mirror left and right, snap to lines rising from the windows, columns and wall corners, and switch between trim white, door green, cedar stain and siding yellow.

- **Main gable:** the main house gable, which has no brackets today.
- **Porch gable:** the porch, with its existing brackets edited out of the photo and redrawn so they can be moved. "As built" shows the original photo.

The roof edges, bracket proportions and shading were measured from the photos. Everything is a single static `index.html` with no build step.
